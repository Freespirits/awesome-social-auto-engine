Built as a companion to [Social Auto Engine](https://github.com/Freespirits/social-auto-engine) — the open-source, multi-channel social media management platform with MCP integration.

## Social Media Schedulers

- [Postiz](https://github.com/gitroomhq/postiz-app) — Open-source social media scheduling tool supporting 30+ platforms with AI scheduling. AGPL-3.0. ~22k stars.
- [Mixpost](https://github.com/inovector/mixpost) — Self-hosted Buffer alternative built with Laravel. MIT (Lite). ~2.1k stars.
- [GrowChief](https://github.com/growchief/growchief) — OSS social automation focused on outreach with workflow node system. AGPL-3.0. ~3k stars.

## Meta / Facebook Libraries

- [facebook-python-business-sdk](https://github.com/facebook/facebook-python-business-sdk) — Official Meta SDK, auto-generated and always current. Covers Ads, Insights, and Conversions API. ~1.2k stars.
- [python-facebook](https://github.com/sns-sdks/python-facebook) — Community-maintained Graph API wrapper covering Pages, Instagram, and Threads. Apache-2.0. ~700 stars.

## Multi-Platform Posting

- [instagrapi](https://github.com/subzeroid/instagrapi) — Reverse-engineered Instagram private API reaching features the official Graph API restricts (Stories, direct Reels). MIT. ~5.8k stars.
- [tweepy](https://github.com/tweepy/tweepy) — Battle-tested X/Twitter API v2 client with media upload support. MIT. ~11k stars.
- [TikTok-Api](https://github.com/davidteather/TikTok-Api) — Unofficial TikTok API for analytics, trends, and competitor monitoring. MIT. ~5.2k stars.
- [linkedin-api-python-client](https://github.com/linkedin-developers/linkedin-api-python-client) — Official LinkedIn API client for personal and company page posting. Apache-2.0. ~400 stars.

## AI Content Generation

- [crawl4ai](https://github.com/unclecode/crawl4ai) — LLM-friendly markdown crawler. Feed it a URL and get structured content for AI-driven hook generation. Apache-2.0. ~50k stars.
- [LLM-Prompt-Library](https://github.com/abilzerian/LLM-Prompt-Library) — Curated, regularly updated prompt collection for copywriting, hooks, and brand voice. MIT. ~1.5k stars.

## MCP Servers

- [meta-mcp-server](https://github.com/oliverames/meta-mcp-server) — 200+ Meta tools covering Pages, Instagram, Threads, and Ads. MIT.
- [awesome-mcp-servers](https://github.com/TensorBlock/awesome-mcp-servers) — Comprehensive index of MCP servers including social media and content platforms. MIT. ~1.5k stars.
- [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) — Official reference MCP servers with best-practice auth, transport, and tool-registration patterns. MIT. ~70k stars.

## HTMX & FastAPI Dashboards

- [CRUDAdmin](https://github.com/benavlabs/crudadmin) — FastAPI + HTMX admin panel with auth and event tracking. Drop-in CRUD for any SQLAlchemy model. MIT. ~700 stars.
- [starlette-admin](https://github.com/jowilf/starlette-admin) — Rich admin panel with file fields, multi-DB support, and advanced filtering. MIT. ~1.7k stars.
- [sqladmin](https://github.com/smithyhq/sqladmin) — Lightweight SQLAlchemy admin for FastAPI. Zero-config CRUD over existing tables. BSD-3. ~2.8k stars.
- [fastapi-htmx-tailwind-example](https://github.com/volfpeter/fastapi-htmx-tailwind-example) — SSE streaming, dialogs, and lazy tables with FastAPI + HTMX. MIT. ~300 stars.

## Approval & Workflow

- [python-statemachine](https://github.com/fgmacedo/python-statemachine) — State machine library with an explicit `ApprovalWorkflow` example. Model lifecycle: draft, pending, approved, scheduled, posted, failed. MIT. ~1.8k stars.
- [Prefect](https://github.com/PrefectHQ/prefect) — Workflow orchestrator with retries, scheduling, and observability. Replace ad-hoc cron with proper orchestration. Apache-2.0. ~19k stars.

## Scraping & Data

- [crawlee-python](https://github.com/apify/crawlee-python) — Apify's open-source framework with Playwright integration and proxy rotation. Self-hosted competitor scraping. Apache-2.0. ~7k stars.
- [Scrapy](https://github.com/scrapy/scrapy) — The reference Python crawler for high-volume scheduled scrapes (trending posts, hashtag analytics). BSD-3. ~55k stars.
- [Xquik](https://github.com/Xquik-dev/x-twitter-scraper) — Agent Skill and API for X/Twitter search, monitoring, exports, media, and confirmation-gated publishing. MIT. ~170 stars. Not affiliated with X Corp.

## Analytics & Insights
