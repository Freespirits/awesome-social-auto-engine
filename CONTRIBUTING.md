# Contribution Guidelines

Thank you for contributing to Awesome Social Auto Engine!

## Adding a new resource

1. Fork this repository
2. Add your resource to the appropriate section in `README.md`
3. Follow this format:

```
- [Name](https://link) — One-sentence description of what it does and why it matters. License. ~Nk stars.
```

4. Keep descriptions concise (one sentence)
5. Add star counts as approximate (e.g. ~2.1k)
6. Include the license
7. Make sure the resource is actively maintained (commits in the last 6 months)
8. Submit a PR with a clear title

## Quality standards

- The project must be open source
- It must be relevant to social media automation, AI content, MCP servers, or dashboard tooling
- It should have a minimum of 100 GitHub stars (exceptions for niche tools that solve a specific problem well)
- No dead projects (no commits in 12+ months)
- No spam, SEO bait, or self-promotion without substance

## Removing a resource

If a listed project is archived, abandoned, or no longer relevant, open an issue or PR to remove it.
